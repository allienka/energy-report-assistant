# Energy Report Assistant

AI-powered platform for analyzing energy and operational reports.

## Project Goals

- Upload CSV and Excel reports
- Generate report summaries
- Detect anomalies and trends
- Answer questions about report data using AI
- Deploy the application to Azure

## Technology Stack

- Python
- FastAPI
- Pandas
- Git & GitHub
- Azure (planned)
- AI / LLM integration (planned)
